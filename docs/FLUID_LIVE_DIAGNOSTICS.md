# 开发版实机液体命令入口

`DEV_EXPERIMENTAL` 构建在插件配置目录监听 `fluid-live-command.json`，由实际游戏的 Framework 线程调用已有 `/combatsim fluid …` 处理器。它不运行另一份模拟，不修改角色或相机，也不提供任意 C# / shell 执行。公开构建不包含入口或轮询。

请求包含 `Id`（每次不同，最多80字符）、`Command`（液体诊断白名单）和 `ExpiresUtc`（未来最多2分钟的 ISO UTC 时间）。单文件最多4096字节，每500ms检查一次，执行或拒绝后删除；写方先写临时文件，再移动到入口，等前一个请求消费后再发下一个。过期、重复、不支持的请求被拒绝。异常隔离在入口内，不中断其它插件功能。

日志记录 execute/completed 和原命令的真实游戏状态。入口路径在插件加载时打印；它不是聊天发送接口。实际验证使用本游戏的 pose/render/碰撞回调，截图取运行中的 FFXIV 窗口，不能以独立物理脚本替代实机。
