# 死亡回放（Death Replay）

状态（2026-11-27）：已实现，两种构建 0 错误，`Tests/DeathReplay` 50 项单元检查全过；**还没有在游戏里看过**（§10）。

用户定的需求（2026-11-27）：Effects 页签新增折叠栏 Death Replay（默认关）；录最近 20 s，死后身体静止时回放最后 N 秒（含倒下过程），按保存的机位依次切换；机位相对死亡时的身体保存；带免费镜头（Cammy 式）编辑机位，飞行时角色不能动；所有写入只是本地渲染状态，任何退出路径都还原；关掉时除一次标志判断外零开销。

## 2. 状态

空闲（功能关 / 没有模拟）→ 录制（模拟进行、玩家活着）→ 等待（玩家倒下：继续录，直到身体静止）→ 回放 → 已回放（直到复活）。复活回到录制；开新一场 / 重置时清空录像重新录。

## 3. 录什么、多少内存

- **谁**：玩家自己 + 模拟里的角色（`NpcSelector.SelectedNpcs`：生成的敌人和被拉进战斗的地图敌人；`CombatCompanionManager.Companions`：队友），离玩家 30 m 内、按距离取最近的 16 个，每 0.5 s 重选一次。观众不录（不是“参与者”，人多时会挤掉真正打的人）。只从对象表里当前存在的对象取地址（不从可能已失效的地址读）。
- **录什么**：每个样本 = 时间 + 骨架的世界变换（位置、旋转、缩放）+ 绘制对象的位置和旋转 + 主骨架的全部骨骼（模型空间，最多 256 根）。脸、头发等部分骨架**不录**，回放时随它们挂的身体骨骼刚性移动（见 §5）——便宜，且表情、头发保持当时的样子。
- **何时**：渲染钩子的只读观察者 `BoneTransformService.OnPosePrepared`（动画、布娃娃和其他所有修改之后、提交之前，即画出来的样子），每秒 30 个样本，只在录制时订阅。
- **压缩**：每根骨骼 14 字节：位置三个 half（1–2 m 处 1 mm，4–8 m 处 4 mm；离线实测 ±2 m 内最大 0.83 mm），旋转四个 16 位分量（读出时归一化）。
- **内存**：每个角色一条 616 样本的环（20 s × 30 + 余量），预先分配，录制时不分配。人形主骨架约 100–125 根（日志里见到 91、101、123）：每条约 616 × 120 × 14 B ≈ 1.0 MB；17 个角色约 18 MB；池子最多留 24 条（离开范围的角色样本留着，需要位置时丢最久没录的），上限约 26 MB；全是 256 根骨骼的大怪物时最坏约 54 MB。实际值写在日志的 10 s 汇总里。
- **开销**：每个样本帧读 17 × ~120 根骨骼并压缩；每 10 s 一行 `DeathReplay: recording N character(s) (B bones a sample) — K samples in the last 10 s, X ms a sample on average, Y ms at most (≈Z ms a second of play); buffer M MB holding S s of you.` 预计每个样本帧零点几毫秒以下（待游戏内读数）。
- 重置、开新一场、换图时清空（角色都换了，接着录会在同一地址上插值出瞬移）。

## 4. 什么时候回放

- 玩家在模拟里倒下的那一帧记下**死亡坐标系**：玩家游戏对象的位置和朝向（死后玩家被冻结，所以就是倒下的位置）。
- 等身体静止：开着布娃娃时先等玩家布娃娃 `IsActive && PhysicsStarted`（15 s 还没开始就不等了），物理开始时重新计时；然后用死亡镜头同一个 `SettleDetector`（七个点最大速度 < 5 cm/s 持续 0.8 s）判断静止。没有布娃娃时同一个检测，即死亡动画播完定住。物理开始（或倒下）后 10 s 还不静止（水里漂、被推着走）也照样回放。
- 另外要求：倒下至少 1 s；身体没被 Enemy Control 抓着；没有过场镜头 / 私有场景 / 游戏自己的过场或 GPose 占着相机（过场死亡镜头播完才开始）。
- 回放的一段：玩家那条录像的最后 N 秒（N = Replay length，3–20 s，默认 8），录得不够就从最早的样本开始；不到 1 s 不放。一次死亡只放一次（循环除外）。

## 5. 怎么回放

- 录制暂停。录过、且现在仍是同一对象（地址 + 对象号 + 实体 id）的角色都回放；已经不在的跳过（日志里有数）。
- **骨骼**：在 `OnFinalPoseModifiers` 里写——回放开始时才订阅，所以排在所有其他修改（包括布娃娃）之后。按时间在两个样本之间插值（位置线性、旋转走短弧的归一化插值），把录下的世界姿态换算到**这一帧**骨架的变换下（`模型 = 当前旋转⁻¹ ×（世界 − 当前位置）÷ 当前缩放`，与布娃娃库写回相同），所以不管角色现在的根在哪，骨骼都在录的位置。挂在身体骨骼上的部分骨架（脸、头发）按那根骨骼写入前后的变化刚性跟着走。
- **绘制对象**：在一个**后订阅**的 framework tick 里写位置和旋转并 `NotifyTransformChanged`（不在渲染钩子里，见 PROJECT_LOG §3 崩溃分析）——它排在插件和所有移动角色的 tick 之后；写它是为了剔除（游戏按绘制对象剔除，见“尸体被抛远后消失”）。
- 不写游戏对象位置、不碰动画状态、不发任何包；角色自己的动画和布娃娃在底下照常跑，只是看不到。
- 校验：每帧在后订阅的 tick 里用对象表确认每个角色还在、记下它的绘制对象；渲染钩子里再查一次游戏对象表的槽位是不是还指向它、绘制对象没换（游戏自己的更新在两者之间，可能删掉地图角色）。
- 速度：回放按真实时间走；循环时 `播放时间 mod 时长`。

### 还原（每条退出路径）

- 停止回放时只改标志，不碰游戏内存（可能是窗口里点的重置）。下一个后订阅 tick：绘制对象回到**游戏对象现在的位置**，加上回放开始时它相对游戏对象的偏移和转角（这期间没动过的角色逐位回到原样）。紧接着的渲染：如果某个角色的姿态自回放最后一次写入后没人改过（三根骨骼的位置逐位相同——游戏不刷新它的姿态），就写回回放开始那一帧的姿态（含部分骨架）；被布娃娃或动画刷新过的不动（它已经是活的）。所以布娃娃从静止姿态接着跑，动画照常继续。
- 退出路径：播完（不循环）、复活、重置、停止模拟、Esc、Stop replay 按钮、关掉功能、开新一场、换图（下一帧还原还在的）、卸载（立即还原，世界还在时）、登出（什么都不碰，角色已不在）、任何异常（停止并还原）。

## 6. 相机

- **所有者**：回放机位 `CameraOwner.DeathReplay = 55`，免费镜头 `CameraOwner.FreeCam = 70`。理由：回放是用户主动打开、自己摆了机位的，要盖过死亡镜头（25）、决斗（16）、Directed（15）和 Follow bone（50）；过场镜头（60）是更短的脚本镜头，回放**等它播完才开始**，所以两者不打架，放在它下面。免费镜头是手动开关的编辑工具，放在最上面（盖过过场镜头）。
- **位姿交接**：第四级——在 `Composition/CameraModule.cs` 里把现有的三级交接（决斗 → 死亡镜头 → 过场）包起来，回放相机最后写；它写了就通知死亡镜头和决斗镜头“被覆盖了”（它们的交接检查不报警）。FoV 经协调者（开始时按投影矩阵量出 FoV 字段与实际镜头的比例，与死亡镜头相同）；游戏的缩放距离、`DirH`、`DirV` 在期间保持（`DirV` 放在可用范围中间，两边都能读到拖动）。
- **机位**：回放时长平分给每个机位，按顺序硬切；循环时机位跟着循环。没有机位：保持回放开始时画面上的视角不动（不交给底下的镜头跟着回放的骨骼走）。
- **放开**：0.3 s 从最后的位姿缓到底下的镜头。回放结束后死亡镜头（Duel 模式）从回放留下的画面重新开始（`DeathShot: resumes`）；Directed 的死亡构图在高于它的所有者放开后自己接上。
- **免费镜头**：
  - 看：游戏相机自己转——拖动时游戏按玩家自己的灵敏度和反转设置改 `DirH` / `DirV`，每 tick 读出与上次写入的差，转动免费镜头（只在鼠标键按着或右摇杆离开中心时算，游戏自己也会转相机），与决斗镜头读拖动的办法相同。俯仰限 ±88°。
  - 飞：W/S 沿视线前后（含俯仰），A/D 左右，E 上，Q 下；Shift ×4，Ctrl ×0.25；基础 3 m/s。滚轮改镜头视角（10°–120°）。插件的输入框在打字时不飞。
  - **角色不动**：用本仓库已证实的办法——`MovementBlockHook` 在 `GameObject.SetPosition` / `SetRotation` 钩子里丢掉游戏对本地玩家的移动（与玩家在模拟中死亡时、Enemy Control 用 WASD 操控凶手时同一层冻结；见 PROJECT_LOG §2“服务器安全屏障”）。新开一个标志 `HoldLocalPlayer`，不和模拟的 `IsBlocking` 共用，免得复活 / 重置把冻结解开。不写玩家的真实位置，不发任何东西。Enemy Control 正在操控敌人时，它在免费镜头开着期间不响应键盘（`KeysTaken`），不然凶手也跟着飞。
  - 退出：再点按钮、Esc、游戏的过场或 GPose 开始、换图、登出、卸载。
- Esc 的顺序：免费镜头开着时先关免费镜头，否则停回放（游戏自己也会处理 Esc，比如打开系统菜单）。

## 7. 界面与设置

Effects 页签 → 折叠栏 **Death Replay**（默认收起）：
- **Enable**（默认关）→ `DeathReplayEnabled`。
- **Replay length (s)** 滑条 3–20，默认 8 → `DeathReplaySeconds`。
- **Loop**（默认关）→ `DeathReplayLoop`。
- 状态行（关 / 录制 N 个角色 / 等身体静止（原因）/ 回放 3.2 / 8.0 s、第几个机位 / 已回放）；回放时旁边有 **Stop replay**。
- **Camera shots**：**Free cam** / **Leave free cam** 按钮、**Add current view**（免费镜头开着时取它的视角，否则取画面上的视角）、`n / 100`、一行“机位相对于：死亡时的身体 / 你现在站的地方”；可滚动列表，每行 `Shot N`、距离和视角、**Go to**（打开免费镜头到该机位）、**Update**（用免费镜头的视角覆盖，免费镜头关着时不可点）、**Delete**、**Up** / **Down**。最多 100 个 → `DeathReplayShots`（每个：相对偏移 X/Y/Z、Yaw、Pitch、Fov，弧度）。
- 机位的坐标系：玩家在模拟里倒下后（直到复活）是死亡坐标系；其余时候是玩家现在的位置和朝向，所以任何地方都能摆机位。偏移在“朝向转过的世界”里：+Z 是朝向，+Y 向上，+X 是朝向左侧。

## 9. 离线检查

`Tests/DeathReplay`（`dotnet run -c Release`，退出码 0 = 全过），50 项：环形缓冲（容量、覆盖最旧、回绕后时间有序、拒绝不递增的时间）、取段（最后 N 秒、被最早样本截断、终点超出、太少）、插值（四分之一处的位置 / 根 / 旋转、跨半球取短弧、首尾外保持、正好落在样本上）、压缩误差（2 万次随机：位置最大 0.83 mm，旋转 < 0.1°）、相对机位（2000 个随机坐标系往返误差 < 1 mm、同一机位在两次死亡里相对身体相同、俯仰和视角保持与限幅、转角约定）、机位时间（平分、边界、不循环时末尾保持最后一个、循环跨多轮按顺序、不均匀平分）、免费镜头一步（右向量、斜向不更快、上是正上）。

## 10. 游戏里看什么

前提：Effects 页签 → **Death Replay** → 勾 **Enable**；开一场模拟。

1. 日志每 10 s 一行 `DeathReplay: recording …`：角色数对（自己 + 30 m 内最多 16 个），每样本耗时和 MB 合理；`FrameCost:` 没有明显变化。
2. **免费镜头**：点 **Free cam** → 画面从当前视角脱离；W/S/A/D/E/Q 飞、Shift / Ctrl 变速、拖动鼠标转向（左右、上下方向对不对——上下若反了是一个常数）、滚轮改视角；**角色原地不动**（看看是否还在原地播跑步动作）；Esc 或 **Leave free cam** 回到原来的相机（0.3 s 缓入）。活着和死后都试；Enemy Control 操控敌人时开免费镜头，敌人不跟着动。
3. 摆两三个机位（**Add current view**），**Go to** / **Update** / **Delete** / **Up** / **Down**。
4. 死一次：身体静止后自动回放最后 N 秒（日志 `replaying …`），机位按顺序切；倒下过程、敌人和队友的动作都在；回放里的身体位置与当时一致（布娃娃被打飞的那段也在）。
5. 回放结束（不循环）：一切回到原样——尸体还在静止的姿势、敌人回到他们现在的位置继续动、相机回到死亡镜头（Duel 模式日志 `DeathShot: resumes`）或 Directed 的死亡构图；没有闪一帧旧姿势。
6. **Loop**：一直循环、机位跟着循环；Esc / **Stop replay** / 复活 / 重置 / 停止都能退出并还原。
7. 机位相对身体：在两个不同的地方、朝不同方向死，同一个机位拍到的身体位置相同。
8. 回放期间换图、卸载插件不崩、不留下错位的模型。

## 11. 已知局限

- VFX、声音、伤害数字、血条不回放；投射物（箭）、掉落的武器、脱落的护甲、分离部件不回放（它们留在现在的位置）。
- 只录主骨架；脸和头发是现在的样子随头刚性移动（表情、头发物理不回放）。骨骼数变了（模型重绘、换装）的角色跳过。
- 手里还拿着的武器跟着手骨的渲染是游戏自己算的，可能晚一帧或停在活着的姿势（待游戏内看）。
- 录制范围之外（> 30 m、或排在 16 个之后）的角色在那段时间里是现在的样子；进入范围前保持他第一次被录到的样子。
- 回放期间模拟还在跑（敌人继续打队友），只是看不到；回放结束直接显示现在的状态。
- 免费镜头不支持手柄移动（只键盘 + 鼠标 / 右摇杆转向）；Esc 也会被游戏自己处理。
- 位置冻结的代价与死亡时相同：免费镜头开着期间，服务器对本地玩家的位置校正被吞掉；按方向键时本地可能播跑步动作。
- 回放没有机位时保持开始时的画面，玩家拖动不转。
