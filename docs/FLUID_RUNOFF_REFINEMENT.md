# 正常尺寸、流动与泛白修正

可见版本 `3567edf` 已推送到 `experiment/body-fluid-rendering-prototype`。本轮改动尚未实机验收，不等同于完整功能通过。

- `fluid on` / `fluid normal` 恢复正常供液和大小；`fluid thick` 单独保留20倍供液、加厚诊断。原单次折射核心不改。
- 胸前落液原先首先全部进入局部薄膜，变成封闭patch库存。现在只补25微米湿痕，余量进入可滑动液珠；使用体积、黏度、局部世界重力决定的滚滑近似，速度受既有 SurfaceSpeed 上限约束。
- 重复顶点接缝只在静态位置及八骨权重一致、边唯一且反向时连接；后台处理，每次实际跨缝还检查当前变形边。真实缺口可脱离成细丝/滴；预算不足仍等待，不能当作缺口。
- 细丝从24节点缩为8节点，取消逐段身体碰撞回吸，仅末端检查地形；独立液滴仍可接触身体并形成移动液珠，脱离后短暂避免皮肤自吸。线程未推进时间保留账目，每次最多请求1/30秒、保留原32子步上限，不无限追帧。
- 表面generation改变时释放旧附着，保留世界液滴、丝和地液；无法重绑定的旧薄湿膜显式退役并报告体积。有效pose中，暂时没有唇点仅停止新供液，不能停止现存世界液体。
- Framework 在覆盖 actor/territory 身份前检查变化，角色或地图变化显式清理所有旧世界液体；衣服/表情引起的同角色采样generation变化不执行这个全量清理。
- 地面首次接触分配到真实碰撞三角形内的相邻格，有限扩展与时间欠账推进；仍限制384 cells、每步2新tile/8新cell/4探测。不是虚构大水洼；未知台阶仍不连接。
- Effects 增加 Cloudiness 和 Foam flecks，Reset 同时恢复两项默认值。米制材料坐标随皮肤/局部液滴携带，随机泛白不逐帧随机；地液用世界XZ。保持默认透明区域，并在厚液体及稀疏微泡处增加乳白感。

泡沫是受厚度与稳定程序纹理调制的艺术效果，不是气泡体积求解；散射背景依据 [PBRT Volume Scattering](https://pbr-book.org/3ed-2018/Volume_Scattering)，亚像素边缘使用 [HLSL fwidth](https://learn.microsoft.com/en-us/windows/win32/direct3dhlsl/dx-graphics-hlsl-fwidth)。无新增纹理资源、原生hook或独立模拟脚本。

必须由真实游戏验证：正常尺寸仍可见；落到胸前后滑动/脱离；倒下持续随mesh更新及世界重力；拉丝存在并自然断裂；地面积液扩大；泡沫无闪烁；冷加载与持续运行性能。本轮只做代码检查和插件编译，遵照用户要求不自行执行游戏命令。
