# 临时加量、加厚查看模式

当前实现状态已提交为 `3b18133`。这批只用于区分正常出液几何太小/太薄与普通材质不可见，不代表真实液体效果已通过验收。

`/combatsim fluid on`（`thick` 为同义命令）启动实际出液路径的临时放大查看模式：

- 供液为当前设置的20倍，仍受原有库存、粒子数量和碰撞查询预算限制。
- 薄表面沿法线加厚：厚度乘16，限制在3至20毫米。干顶点和原覆盖率保持不变。
- 已声明的闭合椭球半径乘4，中心保持原位置；椭球几何与其已有光学尺寸参数同步放大。
- 不增加网格顶点，不保存供液/厚度倍率；本轮查看模式恢复最初材质测试的反光权重1，正常模式仍读取设置。渲染夸张后的体积不等于模拟库存。
- 这个明确的诊断预览允许使用自动选择的实际唇表面候选，无需先运行 confirm-lip；仍要求有效 pose、唇材料锚点及实际表面查询，不能退回 head offset。

`/combatsim fluid inspectnormal` 可查看同一批加厚几何的绿色法线诊断；`inspectoff` 切回普通材质。
`/combatsim fluid off` 清理效果和加厚状态。`fluid normal` 使用正常供液与显示大小。Effects 普通启动和 KO 供液不自动放大。
